# Sample data

`SYNTHETIC_sample_ohlcv.csv` is **synthetic** daily OHLCV data generated by
`scripts/make_sample_data.py` (seed 42). It is not market data.

- Returns follow a GARCH(1,1)-style volatility process with a small drift and **no built-in
  predictability**, so any apparent strategy edge on this file is noise.
- It exists so the CSV-upload path, the dashboard and the tests can be exercised offline.
- Never present results computed on this file as real market performance.

To use it: in the dashboard choose **Upload CSV** and select this file, or run

```bash
python scripts/run_experiment.py --csv data/sample/SYNTHETIC_sample_ohlcv.csv
```
